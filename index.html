01. INGEST

קליטת מסמך

קליטת טקסט נקי, Markdown, DOCX או ODF וניתוק מעיצובי מורשת.

קדם-דפוס נייטיב

05. OUTPUT

פלט מושלם

הדפסה ללא תקלות, סימני חיתוך וארכיב .tok אטומי מוגן.

הורדת גרסת קדם-השקה והידור מתוך הקוד

פרויקט TypesetOK (TOK) מפותח בקוד פתוח. ניתן להוריד ולהדר את המערכת ישירות מתוך מאגר הקוד באמצעות כלי הפיתוח הרשמיים של שפת Rust:

# 1. Clone the repository
git clone https://github.com/TypesetOK/typesetok.git
cd typesetok

# 2. Build Rust Engine Workspace (7 Crates)
cargo build --workspace --release

# 3. Run full verification suite (58 passing tests)
cargo test --workspace

# 4. Export ISO PDF/X-1a pre-press demo
cargo run -p tok-cli -- render-pdf --demo output.pdf
דרישות מוקדמות:
  • Rust 1.85+ (עם מנהל החבילות Cargo)
  • Node.js 20+ (עבור מעטפת שולחן העבודה של Electron)
  • תמיכה במערכות הפעלה: Windows 10/11, macOS 12+, Linux

דו״ח ארכיטקטורה הנדסי: TypesetOK (TOK)

עקרונות היסוד הארכיטקטוניים

1. עצמאות מוחלטת של מודל המסמך (TDM): מודל המסמך מנותק לחלוטין מ-DOM, מתגיות HTML ומחוקי CSS של הדפדפן. כל המבנים הסמנטיים כתובים ב-Rust טהור.

2. עקרון ה-Pre-Pagination: מנוע ה-UI אינו מורשה לנחש שבירות עמודים או חלוקת טורים. ליבת ה-Rust מבצעת את כל חישובי Knuth-Plass ומעבירה דפים שכבר עברו חלוקה מראש.

3. צינור PDF דואלי: שכבת תצוגה מבוקרת ומהירה למסך (HTML/CSS & Canvas Overlay) לצד צינור קדם-דפוס נייטיב עצמאי לחלוטין ב-Rust המפיק PDF/X-1a תקני עם 100% K Black ו-BleedBox של 3 מ"מ.

4. שכבת סמן וירטואלי (<16ms Caret): עקיפת כשלי contenteditable המובנים בדפדפנים בעזרת שכבת Canvas שקופה וסמן וירטואלי ב-120 FPS.

5. תמיכה מובנית במסמכי ענק: אלגוריתם עימוד אינקרמנטלי מבוסס התכנסות (Convergence Pagination) ווירטואליזציה מלאה של 3 עמודים פעילים בלבד.
